# 聊天统计

运行 `.\run.ps1 stats` 即可生成本地统计页，命令输出文件路径。正式 build 和每日 update 也会刷新统计，并从本地阅读首页提供入口。默认显示全部已入库消息，可按北京时间选择某天、自然周（周一至周日）、自然月或自定义起止时间。自定义区间包含起点，不包含终点。

只使用 SQLite 当前版本的消息。文字、图片、表情、引用和其他类型各按一条消息计数。字数统计 text 和 quote 的本人正文，按 Unicode 码点排除空白，包含标点及表情符号；引用摘录和媒体占位不计。系统与未知发送者单列。时间未知的记录另报数量，不参与分时统计。

每人分别显示发言天数、活跃分钟数（有发言的不同自然分钟）、首末发言、每小时条数及最高峰小时。同一分钟内多条只算一个活跃分钟。该指标衡量发言分布，无法测量阅读或在线时长。所有计算在本机完成；统计页仅写入北京时间、角色与字数，不复制聊天原文。
