# 聊天统计

运行 `.\run.ps1 stats` 即可生成本地统计页，命令输出文件路径。正式 build 和每日 update 也会刷新统计，并从本地阅读首页提供入口。默认显示全部已入库消息，可按北京时间选择某天、自然周（周一至周日）、自然月或自定义起止时间。自定义区间包含起点，不包含终点。

只使用 SQLite 当前版本的消息。文字、图片、表情、引用和其他类型各按一条消息计数。字数统计 text 和 quote 的本人正文，按 Unicode 码点排除空白，包含标点及表情符号；引用摘录和媒体占位不计。系统与未知发送者单列。时间未知的记录另报数量，不参与分时统计。

每人分别显示发言天数、活跃分钟数（有发言的不同自然分钟）、首末发言、每小时条数及最高峰小时。同一分钟内多条只算一个活跃分钟。该指标衡量发言分布，无法测量阅读或在线时长。所有计算在本机完成；统计页保存时间、角色和字数等派生数据；为逐条核验发起归属，另包含候选附近的原文和证据 ID。

## 时间分段指标和旧版对照

归档按消息时间、来源顺序、稳定 ID 排序。只用有时间的双方发言计算轮次，包括图片和表情。相邻双方发言间隔超过 90 分钟就另起一场；跨午夜不会自动重置。全库第一场缺少更早记录，首条发言不计入发起次数。后续每场的首条发言给该发送者计一次发起。

同一场内，同一人连续发言合为一个发言回合。换人时，用新回合第一条的时间减去上一回合最后一条的时间，归给接话的人。平均回复间隔是这些间隔的算术平均，并显示样本数。它衡量相邻发言的时间，不要求存在微信显式引用。每场相邻两个回合组成一轮完整往返，不重叠配对，按第二个回合开始时计数。单方独白只算一个回合。“单场最多”取各场在所选区间内完成的往返轮数的最大值。

话题转换取当前正式检索清单中的 Topic Segment，在同一个 Conversation Block 内切换到不同 segment_id 时计一次；每个 Block 的首话题、续卷均不计。它是基于语义分段的估计。清单缺失、离线构建或清单与当前消息不一致时显示不可用。

先用全库上下文判定事件，再按事件时间筛选。发起按首条、回复及回合按接话时刻、话题转换按新段首条的北京时间归属。切换日期或查询范围不会凭空产生发起、回复或话题转换。

## 对照组长度、回复分布与话题接续

长度比较按开场时间选样，向后看完整已观察对话。首场缺少前序记录，末场缺少下一次间隔确认，均不进入已结束场次比较。单方发言计零轮。显示双方各自的样本数、总轮数、每场平均、中位数、最长和达到长聊门槛的比例；默认至少 5 轮，可调整。明细显示每场起止和轮数。

回复分布按换人时刻筛选，分别计算同场接话（≤90分钟）与跨场换人（>90分钟）的 P25、P50、P75、P90。使用排序后位置 (n−1)p 的线性插值。跨场换人仅表示停顿后换人发言。

话题按正式语义清单的分段统计，续卷合并。以每段首条有时间的参与者发言归属引入方，并按该时刻筛选。首个已观察段的开头未知，排除。分别显示引入段数、其中同 Block 内换题数，以及对方在同段随后发言的段数和比例。持续接续要求对方至少有两个分开的发言回合。表情也算发言。末段只计截至快照可见的接续。该口径衡量可观察的参与行为，不对是否提出原创观点做语义判断。

## 发起归属的语义核验（现行口径）

旧版 90 分钟开场与长度作为对照保留。默认只采纳人工判定；未审核行暂按不确定处理，同时单列待核数。模型预估为另一个可选视图。对每个严格超过 90 分钟的间隔读取前后语境及显式引用，模型给出新发起、延迟回复或不确定，并列出证据消息 ID 和理由。离线或请求失败时保留待核。敏感性分析分别以 90 分钟、3、6、12、24 小时筛选候选，其他计算规则相同。旧版回复间隔分布仍使用时间分段。

新发起开启有归属的新场；延迟回复延续上一场，换人按一次回合计算。同一人补充未完话题也归入延续类。不确定边界隔离两侧，受影响的未闭合场次不进入完整长度比较。全库首场和最后未闭合场继续排除。范围筛选按候选或已归属场次的开头计，计算整场长度可以使用范围之后的消息。

本地统计页可展开逐条核验、打开阅读页原文、修改判定和预览影响。下载核验文件后用 `.\run.ps1 review-starts 文件路径` 写入私有归档，刷新页面即可读取；之后的每日构建复用审核。候选 ID 与上下文摘要共同校验；上下文变化使旧判定失效。统计页包含模型理由及候选证据，保存在本机。模型建议仅使用配置的模型服务。
